# Инвентарь железа (полигон проекта)

Опознано по фотографиям владельца, 2026-08-03. Это тестовый парк femus:
каждый модуль — будущий драйвер и пункт hardware-чеклиста.

## Платы-контроллеры

| Плата | Чип | Подключение | Роль |
|---|---|---|---|
| Arduino Nano V3 («LISA 2011») | ATmega328P | mini-USB (CH340) | **основная плата Firmata-адаптера**; в Arduino IDE выбирать Processor: «ATmega328P (Old Bootloader)» |
| Arduino Pro Mini | ATmega328P | через USB-TTL | запасная; YP-01 без DTR → прошивка с ручным reset |
| Raspberry Pi 4 Model B | BCM2711 | самостоятельная | Linux-адаптер (план 2) |
| ESP-01S | ESP8266EX | UART | будущее: Firmata-over-WiFi / самостоятельный узел |
| Digispark | ATtiny85 | micro-USB (V-USB) | вне скоупа (8 КБ, Firmata не влезает) |
| Безымянная чёрная плата | STM8S105K4T6 | SWIM (нужен ST-Link) | вне скоупа v1 |

## Модули по классам femus

### UART / AT (класс Uart, планы 5+)
- **SIM800L** (красный breakout) — GSM 2G. ⚠️ Питание 3.4–4.2 В, броски до 2 А —
  НЕ подключать к 5V-пину Arduino, нужен отдельный источник. Антенна обязательна.
- **SIM5216E** на плате SIMCOM WCDMA EVB — 3G/WCDMA, RS232+USB, слот SIM.
  ⚠️ Проверить, что оператор ещё держит 3G-сеть.
- **Beitian BN-220** — GPS, UART/NMEA 9600, будущий драйвер Gps.
- **HC-05/06** — Bluetooth-UART-мост (logic 3.3V, питание 3.6–6 В).
  Идея: беспроводная Firmata (Arduino ↔ PHP без кабеля).
- **YP-01 USB-TTL** — переходник для прямого подключения UART-модулей к компьютеру
  (без DTR — для прошивки Pro Mini неудобен).

### I2C (план 3)
- **TEA5767** (синяя платка) — FM-приёмник, пины +5V/SDA/SLC/GND.
- LCD 1602, GY-521 (MPU-6050), DS-1307 — из кита Elegoo (см. фото кита).

### Тайминго-критичные (план 4)
- **HX711** (MH, пины E+/E−/A−/A+/B−/B+ и GND/DT/SCK/VCC) + тензодатчики-балки.

### Радио-контуры (взаимная верификация)
- **FS1000A (TX) + MX-RM-5V (RX)** — 433 МГц пара → замкнутый контур «передали строку → приняли».
- **LCD_FM_TX_V2.2.1** (FM-передатчик, JL-чип, управление через пады TX/RX = UART,
  micro-USB питание, вход jack + микрофон) + **TEA5767** (FM-приёмник, I2C) →
  полный FM-контур без человека: TX вещает на частоте → RX подтверждает захват.

### Кит Elegoo (37-in-1) — цифровые/аналоговые
PIR HC-SR501, ультразвук HC-SR04, кнопки, реле, зуммеры, лазер, фоторезистор,
холл, наклон, вибро, пламя, DHT11, джойстик, энкодер, клавиатура 4x4,
уровень воды, LCD1602, RGB-LED, ИК приёмник/передатчик — покрывают классы
DigitalPin/AnalogPin и уже частично реализованы (Button, MotionSensor, Relay,
Led, Buzzer в v1).

### Дополнено 2026-08-03 (вторая партия фото)
- **DFPlayer Mini** — MP3-плеер с microSD, управление по UART (9600) — будущий драйвер
  AudioPlayer: озвучка событий («движение обнаружено» голосом)
- **KY-040** — энкодер вращения (CLK/DT/SW) — цифровой класс, план digital-расширений
- **MB102** — блок питания макетки (VIN 7–12В → 3.3/5В, джамперы) — им же питать SIM800L
- **DS18B20** (водозащищённый щуп + Plugable Terminal) — термометр 1-Wire; на Pi через
  w1-therm overlay, на Arduino — OneWire-модуль ConfigurableFirmata
- **Cinterion EHS5-E** (eval board EHS5/6/8) — второй 3G-модем с AT-командами; та же
  оговорка про живость 3G-сети, что и у SIM5216E
- Стартовый кит: макетка, MB102, резисторы/конденсаторы, LEDs, кнопки, зуммеры,
  оптопара 4N35, сдвиговый регистр (74HC595), транзисторы, потенциометр — обвязка

### Дополнено 2026-08-03 (третья партия фото)
- **STM32MP157C-DK2 Discovery Kit** — Linux-MPU плата (2×Cortex-A7 650МГц + M4,
  4" TFT touch, WiFi/BT LE, Gigabit Ethernet, 40-pin RPi-совместимый разъём GPIO).
  ⭐ Второй целевой девайс Linux-адаптера (план 2): тот же libgpiod, что и на Pi
- **HY32D** — 3.2" TFT LCD (ILI932x, параллельная 16-битная шина + touch) — вне
  универсального слоя v1 (как OV7670); возможен на STM32MP1/Linux через fbdev
- **mikroElektronika TFT Developer kit 3 (XMEGA)** — mikromedia + mikroC — отдельная
  экосистема, вне скоупа femus
- **Cinterion DSB Multi Adapter A4** — несущая плата для модемов Cinterion
  (HC25/MC75/MC55/EHS5) — вместе с EHS5-E это полноценный GSM-стенд с AT-доступом
- **AVR dev board** (ATmega32(?), LCD1602, кнопки, DIP-переключатели, USB-UART FT232,
  JTAG/ISP) — учебная AVR-плата; для femus вне скоупа (нет Arduino-загрузчика из коробки)
- **Собранная макетка**: Arduino Nano V3 + XFW-HX711 + HC-05 уже разведены —
  готовый стенд для плана 4 (LoadCell) и беспроводной Firmata
