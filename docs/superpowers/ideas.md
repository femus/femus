# Бэклог идей владельца (2012–2019, записано 2026-08-04)

## 1. Умная кладовка ⭐ кандидат во флагманское приложение
Весы под банками (тензодатчик + HX711), PHP считает остаток и расход
(«сахара 340 г, уходит 50 г/день, хватит на неделю»). Вывод: LCD1602 (готов) /
веб-дашборд (фаза 2) / MQTT → Home Assistant (фаза 2). Несколько банок:
каналы A/B HX711 + мультиплата (готова). Зависимость: план 4 (LoadCell).
План: examples/pantry/ как сквозная витрина после плана 4.

## 2. SMS по радиоканалу («рация с текстом»)
На 433 МГц (FS1000A+RX пары с обеих сторон) — после прошивочного радио-модуля;
дальность десятки метров. Гибрид-демка: SIM800L принимает SMS → ретрансляция
по 433 МГц → удалённый узел с LCD. Для серьёзной дальности докупить LoRa
(Meshtastic-ниша).

## 3. GSM-интернет-радио → FM (идея 2012, как пасхалка)
Pi: PHP тянет интернет-радиопоток → аудиовыход → джек FM-передатчика LCD_FM_TX;
femus настраивает частоту. Приёмник — любое FM-радио / TEA5767 (замкнутый контур).
Ценность: демка FM-драйвера, не продукт.

## 4. Термоэлектрический генератор на Пельтье
Сам генератор — вне скоупа (физика/силовая). femus как измерительная лаборатория:
DS18B20 горячая/холодная сторона, напряжение через AnalogPin с делителем,
график КПД от ΔT. Зависимости: 1-Wire (roadmap), analog (готов).

## Мелочи из hardware-прогонов (2026-08-04)
- LCD1602 владельца (QAPASS 1602A) — БЕЗ I2C-бэкпака, параллельный. Покупки: бэкпак
  PCF8574 (~$1). Бэклог: драйвер параллельного HD44780 (6 GPIO: RS, EN, D4-D7 в
  4-битном режиме через Firmata digital) — тогда бэкпак не нужен.

## Требования к радио-модулю femus (из обсуждения 2026-08-04)
Радио — широковещательное: адресация узлов (0-255), CRC, повторы — в протоколе
с первого дня (RadioHead RHDatagram / аппаратный пакетник Si4432). Без шифрования —
только несекретные данные. Предпочтительное железо: 2× Si4432 (RH_RF22), фолбэк —
2× пары FS1000A (RH_ASK).

## ФЛАГМАН №1: Радио-мессенджер (утверждено 2026-08-04)
Телефон ⇄ компьютер без интернета и сотовой связи, через 433 МГц.
Узел A (станция): Mac PHP+femus → Nano#1+FemusFirmata+RadioFeature → FS1000A+RX.
Узел B (мобильный): iPhone SwiftUI-терминал (CoreBluetooth) → HM-10 (BLE-UART, есть!)
→ Nano#2 с мост-скетчем (BLE⇄радио) → FS1000A+RX.
Компоненты работ: (1) план 6 — RadioFeature для ConfigurableFirmata (RadioHead RH_ASK,
sysex: SEND/RECV, адресация+CRC+повторы) + PHP RadioLink; (2) мост-скетч узла B;
(3) SwiftUI-терминал (без публикации, free provisioning); (4) схемы двух узлов в docs.
Демо: выключить WiFi/сотовую → переписка идёт. Апгрейд позже: 2× Si4432 (RH_RF22).
ФЛАГМАН №2 (следом): умная кладовка = станция с весами + BLE + приложение.

## femus firmware:flash (в CLI-план)
Раздавать готовые .hex FemusFirmata (компилировать в CI) + команда `femus firmware:flash
[--port]` через arduino-cli upload: пользователю не нужны Arduino IDE и библиотеки.
Принцип прошивок: FemusFirmata = универсальные сервисы (вся логика в PHP);
спец-скетчи (RadioBleBridge) — только для узлов без компа, конфиг константами + README;
позже — конфигурация таких узлов по BLE + EEPROM.
