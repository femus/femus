# MPU-6050 Gyroscope/Accelerometer (GY-521 module)

## Wiring to Arduino (Firmata)

| GY-521 pin | Arduino |
|------------|---------|
| VCC        | 5V      |
| GND        | GND     |
| SDA        | A4      |
| SCL        | A5      |

Address is 0x68 (0x69 if pin AD0 is pulled to power: `$board->mpu6050(0x69)`).

## Code

```php
$mpu = $board->mpu6050();
$a = $mpu->readAccel();   // ['x' => g, 'y' => g, 'z' => g]
$g = $mpu->readGyro();    // ['x' => °/s, ...]
$t = $mpu->readTemperature();
```

Board lying flat on a table → z ≈ +1.0g, x and y ≈ 0.

## Verification

`php examples/gyro-dump.php <port>` — tilt the board and the axis values change.
