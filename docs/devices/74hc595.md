# 74HC595 Shift Register (8 outputs from 3 pins)

Serial-in/parallel-out register: the board clocks bits in over 3 wires, the chip
drives 8 outputs. Chain several chips (Q7' → DS of the next) to get 16, 24, ...
outputs from the same 3 pins.

## Pinout (DIP-16, notch up)

```
        ┌───∪───┐
    Q1 ─┤ 1  16 ├─ VCC (5V)
    Q2 ─┤ 2  15 ├─ Q0
    Q3 ─┤ 3  14 ├─ DS    (data    → D2)
    Q4 ─┤ 4  13 ├─ OE    (→ GND: outputs always on)
    Q5 ─┤ 5  12 ├─ STCP  (latch   → D4)
    Q6 ─┤ 6  11 ├─ SHCP  (clock   → D3)
    Q7 ─┤ 7  10 ├─ MR    (→ 5V: never reset)
   GND ─┤ 8   9 ├─ Q7'   (serial out → DS of the next chip)
        └───────┘
```

## Wiring to Arduino (Firmata)

| 74HC595 pin | Arduino |
|-------------|---------|
| VCC (16), MR (10) | 5V |
| GND (8), OE (13)  | GND |
| DS (14)     | D2 (data)  |
| SHCP (11)   | D3 (clock) |
| STCP (12)   | D4 (latch) |

LEDs: Q0..Q7 → 220 Ω resistor → LED → GND.

Daisy chain: Q7' (9) of the first chip → DS (14) of the second; SHCP and STCP
are shared by all chips.

## Usage

```php
$sr = $board->shiftRegister(dataPin: 2, clockPin: 3, latchPin: 4); // chips: 2 for a chain

$sr->set(0, true);       // output Q0 on
$sr->write(0b10101010);  // whole byte at once (bit n = Qn)
$sr->clear();            // everything off
```

Outputs start all-off: the driver flushes zeros at construction because the
register powers up with garbage.

## Gotchas

- No timing requirements — the chip follows any clock the board can produce, so
  plain Firmata digital writes are fine (no custom firmware needed).
- OE left floating = flickering/ghost outputs. Tie it to GND.
- MR left floating = random resets. Tie it to 5V.
- Each output sources ~20 mA max (70 mA total per chip) — LEDs are fine, motors
  and relay coils need a transistor.
