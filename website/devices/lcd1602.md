# LCD 16x2 (I2C backpack PCF8574)

## Wiring to Arduino (Firmata)

| Backpack pin | Arduino |
|--------------|---------|
| VCC          | 5V      |
| GND          | GND     |
| SDA          | A4      |
| SCL          | A5      |

The default address is 0x27 (some modules use 0x3F: `$board->lcd1602(0x3F)`).
If the screen is blank — turn the contrast potentiometer on the backpack.

## Breadboard

```
      Arduino Nano
      ┌─────────┐
   5V │ ●       │
  GND │ ●       │
   A4 │ ●       │  (SDA)
   A5 │ ●       │  (SCL)
      └─────────┘
        │   │   │   │
        │   │   │   └── A5 (SCL) ── LCD backpack SCL
        │   │   └─────── A4 (SDA) ── LCD backpack SDA
        │   └─────────── GND rail (blue) ── LCD backpack GND
        └─────────────── 5V rail (red)  ── LCD backpack VCC

  I²C bus: SDA and SCL each go directly from Nano header pins to the
  corresponding pins on the PCF8574 backpack (4 wires total).
```

Resistors: none needed — the PCF8574 I²C backpack module includes onboard
pull-up resistors on SDA and SCL; do not add external pull-ups or you will
overdrive the bus.

**Common mistakes**

1. Swapping SDA (A4) and SCL (A5) — the LCD initialises but shows garbage or
   nothing; double-check the label on the backpack before powering on.
2. Blank screen after correct wiring — the contrast potentiometer on the back
   of the PCF8574 backpack must be turned; fully clockwise or counter-clockwise
   is often fine, the sweet spot is somewhere in between.
3. Wrong I²C address — some PCF8574A chips use 0x3F instead of 0x27; use
   `$board->lcd1602(0x3F)` if the default does not respond.

## Code

```php
$lcd = $board->lcd1602();
$lcd->write('Hello');
$lcd->setCursor(0, 1);
$lcd->write('femus!');
```

## Verification

`php examples/lcd-clock.php <port>` — the first line shows "femus", the second
line shows the ticking time. See
[`examples/lcd-clock.php`](https://github.com/femus/femus/blob/main/examples/lcd-clock.php).

## Parallel wiring (no I2C backpack)

Wire the LCD data lines directly to GPIO pins. **RW must be tied to GND** (the driver is write-only).

| LCD pin | Function  | Arduino Nano |
|---------|-----------|--------------|
| VSS     | GND       | GND          |
| VDD     | Power     | 5V           |
| VO      | Contrast  | see note     |
| RS      | Register  | D7           |
| RW      | Read/Write| GND (tie)    |
| E       | Enable    | D8           |
| D4      | Data 4    | D9           |
| D5      | Data 5    | D10          |
| D6      | Data 6    | D11          |
| D7      | Data 7    | D12          |
| A       | Backlight+| 5V           |
| K       | Backlight-| GND          |

**Contrast (VO):** connect the middle pin of a 10 kΩ trimmer between 5V and GND.
Quick hack — a 1–2 kΩ resistor to GND, or GND directly for maximum contrast.

```php
$lcd = $board->lcd1602Parallel(7, 8, 9, 10, 11, 12);
$lcd->write('Hello');
$lcd->setCursor(0, 1);
$lcd->write('femus!');
```

`php examples/lcd-clock-parallel.php <port>` — the first line shows "femus", the
second line shows the ticking time. See
[`examples/lcd-clock-parallel.php`](https://github.com/femus/femus/blob/main/examples/lcd-clock-parallel.php).
