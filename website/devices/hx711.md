# HX711 Load Cell Amplifier (Digital Scale)

## Wiring to Arduino (Firmata)

| HX711 pin | Arduino |
|-----------|---------|
| VCC       | 5V      |
| GND       | GND     |
| DT (DOUT) | D3      |
| SCK       | D2      |

| Load Cell wire | HX711 pin |
|----------------|-----------|
| Red (E+)       | E+        |
| Black (E−)     | E−        |
| White (A−)     | A−        |
| Green (A+)     | A+        |

## Breadboard

```
      Arduino Nano
      ┌─────────┐
   5V │ ●       │
  GND │ ●       │
   D3 │ ●       │  (DT / DOUT)
   D2 │ ●       │  (SCK)
      └─────────┘
        │   │   │   │
        │   │   │   └── D2 ────── HX711 SCK
        │   │   └─────── D3 ────── HX711 DT (DOUT)
        │   └─────────── GND rail (blue) ── HX711 GND
        └─────────────── 5V rail (red)  ── HX711 VCC

  Load cell (four-wire Wheatstone bridge):
  HX711 E+ ── Red wire   (excitation +)
  HX711 E− ── Black wire (excitation −)
  HX711 A+ ── Green wire (signal +)
  HX711 A− ── White wire (signal −)

  The load cell wires plug directly into the screw terminals on the HX711
  breakout board; no breadboard rows are needed for the load cell itself.
```

Resistors: none needed — the HX711 module includes an onboard instrumentation
amplifier with differential inputs; the load cell is a passive bridge that
requires no additional resistors on the breadboard.

**Common mistakes**

1. Swapping DT and SCK — the driver will get stuck waiting for the data line
   to go low; readings never arrive; swap the D2/D3 jumpers and retry.
2. Swapping load cell wires (e.g. A+ ↔ A−) — the scale will read negative
   values under load; reverse the A+/A− pair at the screw terminals.
3. Running the load cell cable near power wires — the HX711 is a 24-bit ADC
   sensitive to noise; route the load cell cable away from 5V/GND lines and
   keep it as short as practical.

## Firmware Requirement

The HX711 requires **FemusFirmata** — not the standard Firmata sketch. See the
[firmware guide](/guide/firmware) for flashing instructions.

## Code

```php
use Femus\Board;

$board = Board::firmata('/dev/ttyUSB0');

// Configure: load cell on DT=D3, SCK=D2, threshold=1.0 gram
$cell = $board->loadCell(3, 2, thresholdGrams: 1.0);

// React to weight changes
$cell->onChange(function (float $grams) {
    printf("Weight: %.1f g\n", $grams);
});

// Wait for first reading, tare (zero), calibrate
echo "Waiting for first reading...\n";
$start = time();
while ($cell->raw() === null) {
    if (time() - $start > 5) {
        echo "Timeout: no reading from HX711\n";
        exit(1);
    }
    $board->loop()->tick(0.1);
}

$cell->tare();
echo "Tared. Place a known weight (e.g. 100 g) on the scale.\n";

// Calibrate: after placing the weight, call
// $cell->calibrate(100.0);  // 100 grams
// echo "Calibrated. Now grams() returns true values.\n";

$board->run();
```

## Verification Steps

1. **Before load cell**: Power and data lines only (no weight). Call `tare()` to zero the offset.
2. **With known weight**: Place a calibration object (e.g. 100 g standard weight or a 6.1 g coin stack) on the load cell.
3. **Calibrate**: Call `$cell->calibrate(100.0)` (use the actual weight in grams).
4. **Verify**: Remove the weight and re-place it. The `grams()` output should match.

## LoadCell API

- `raw(): ?int` — Raw ADC value (null until first reading arrives).
- `tare(): void` — Set current reading as zero reference.
- `calibrate(float $grams): void` — Set the current raw value to correspond to `$grams`.
- `grams(): float` — Weight in grams (requires prior calibration).
- `onChange(callable): void` — Register a callback triggered when weight crosses the threshold.
- `waitForWeightAbove(float $grams, ?float $timeoutSeconds = null): bool` — Block until weight exceeds value or timeout. (null = block until the weight is reached)
