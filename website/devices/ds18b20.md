# DS18B20 1-Wire Thermometer (Raspberry Pi)

A Dallas DS18B20 digital thermometer — the classic waterproof-probe temperature
sensor. On a Raspberry Pi femus reads it through the Linux kernel's 1-Wire
driver, so no firmware and no Arduino are involved: just three wires into the
[Pi's GPIO header](/guide/linux-board).

## Enabling 1-Wire on the Pi

Once per Pi: add the overlay to `/boot/firmware/config.txt` and reboot.

```
dtoverlay=w1-gpio
```

After reboot the kernel lists every sensor on the bus under
`/sys/bus/w1/devices/28-*`.

## Wiring

| DS18B20 wire | Raspberry Pi |
|--------------|--------------|
| DATA (yellow) | GPIO4 (pin 7) |
| VCC (red)     | 3V3 (pin 1)  |
| GND (black)   | GND (pin 6)  |

Plus a **4.7 kΩ pull-up resistor between DATA and VCC** — the 1-Wire bus does
not work without it. Multiple sensors share the same three wires: they all sit
on the bus and are told apart by their unique IDs.

## Usage

```php
use Femus\Board;

$board = Board::linux();                 // run this on the Pi itself

$sensors = $board->oneWireDevices();     // ['28-0301a279...', ...]
$thermometer = $board->ds18b20();        // first sensor, or ds18b20('28-...') for a specific one

$c = $thermometer->celsius();            // null on a failed read (bad CRC)
$f = $thermometer->fahrenheit();
```

Readings are CRC-checked: a disturbed bus (loose wire, missing pull-up) yields
`null` instead of a bogus temperature — check for it in anything that acts on
the value. See
[examples/pi-temperature.php](https://github.com/femus/femus/blob/main/examples/pi-temperature.php)
for a complete polling loop.

## Gotchas

- **No pull-up, no sensor.** The most common failure: `oneWireDevices()` returns
  an empty list because the 4.7 kΩ resistor is missing.
- A read takes ~750 ms inside the kernel driver — poll every couple of seconds,
  not in a tight loop.
- Parasite-power wiring (two wires) is not recommended; use all three.
- On Arduino boards the DS18B20 needs a OneWire firmware module — that path is
  on the roadmap; today this driver is Raspberry Pi (Linux) only.
