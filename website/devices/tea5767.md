# FM Receiver (TEA5767)

The blue TEA5767 module: an FM tuner on I2C with its own headphone amplifier, an
antenna jack and a headphone jack. femus tunes it and reads the signal; the sound goes
straight from the module to your headphones.

## Wiring to Arduino (Firmata)

| TEA5767 pin | Arduino Nano |
|-------------|--------------|
| +5V         | 5V           |
| GND         | GND          |
| SDA         | A4           |
| SLC (SCL)   | A5           |

The address is fixed at 0x60. Plug a ~75 cm wire (a quarter wave at 100 MHz) or the
telescopic antenna from the kit into **ANT**, and headphones into the audio jack.
The headphone output is too weak for a bare speaker — use a powered speaker or an
amplifier module such as a PAM8403.

**Common mistakes**

1. SDA and SCL swapped — the board answers, the module does not. Swap A4 and A5.
2. No antenna — the scan finds nothing, or only the one strongest local station.
3. Silence right after power-up — normal. The chip plays nothing until it is tuned.

## From the command line

```bash
vendor/bin/femus fm:scan               # list stations, stay on the strongest
vendor/bin/femus fm:tune 101.3         # switch to another one
vendor/bin/femus fm:scan --min-level=9 # set the station bar by hand
```

The module keeps playing after the command exits, as long as the board stays powered.

## Live spectrum in the browser

```bash
php examples/fm-spectrum.php /dev/cu.usbserial-XXXX   # then open http://localhost:8080
```

The receiver sweeps the band one step at a time and the page draws every level as it lands:
stations rise out of the noise floor (the dashed line) and get their frequency on top.
Click a peak or a station below the chart and the sweep pauses while it plays; **Resume sweep**
carries on. A full sweep takes about 17 seconds — the I2C round trip over Firmata sets the pace.

## Code

```php
$radio = $board->tea5767();            // tea5767(deEmphasis75us: false) in Europe

$radio->tune(101.3);
$radio->status();                      // ['frequency' => 101.3, 'level' => 13, 'stereo' => true]

$points = $radio->scan();              // every 0.1 MHz across 87.5–108, muted while it runs
$stations = Tea5767::stations($points); // peaks at least 3 above the noise floor
```

`level` is the chip's own signal meter, 0–15. Empty air still reads 6–9 on it, depending on
the antenna, so a station is a peak that stands at least 3 above the band's median level. The chip has no RDS, so there are no station
names — only frequencies and levels.

De-emphasis is 75 µs in the Americas (the default) and 50 µs in Europe and most of the
world; the wrong one makes the sound slightly dull or slightly harsh, nothing worse.
